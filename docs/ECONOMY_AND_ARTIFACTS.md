# Economy and Empowered Artifacts

Use integer smallest currency units internally.

The server owns balances, prices, purchases, sales, rewards, fees, and transaction settlement. Never trust client-supplied totals.

Support stalls, limited stock, buying, selling, and later rare rotating stock.

Confirmed player trades settle atomically: all transfers succeed or none do. Changing an offer invalidates previous confirmation.

Rare empowered artifacts may grant bounded capabilities such as selected player inspection, hidden-exit revelation, temporary local weather change, short-range teleport, hidden-player detection, remote viewing, or restoring health/stamina.

Balance with charges, cooldown, range, duration, recharge cost, rarity, visibility, and scope.

No unrestricted god mode or access to SQL, admin commands, private communications, account data, arbitrary currency creation, or unrestricted world editing.
